# 故障排查与常见问题

按"现象 → 原因 → 解决"组织。解决不了时：按 F12 打开浏览器控制台，把红色报错截图发给 AI 助手，附上这句话："我在跑 gesture-sketchbook 项目（本地 node scripts/serve.js 启动），报错如下，请帮我定位。"

## 摄像头问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 弹窗"摄像头权限被拒绝了" | 之前点过"拒绝"，浏览器记住了 | 点地址栏左侧的锁/摄像头图标 → 把摄像头改为"允许" → 点页面"重试摄像头"。也可打开 `chrome://settings/content/camera` 检查 |
| 弹窗"没有检测到摄像头" | 无摄像头/被物理开关关闭 | 检查笔记本摄像头物理挡板与开关；外接摄像头换 USB 口 |
| 弹窗"摄像头被其他程序占用了" | Zoom/OBS/腾讯会议等正在用 | 关闭占用摄像头的软件 → "重试摄像头" |
| 页面卡在"正在打开摄像头…" | 驱动异常或被安全软件拦截 | 重启浏览器；设备管理器里检查摄像头驱动 |
| 想先体验不想开摄像头 | — | 点"演示模式"，虚拟手会自动演示全部手势 |

## 识别与交互问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 手伸过去了但不画 | 光线太暗/背景太乱/手太远 | 打开灯，面对纯色背景，手掌距镜头 30-60cm 且画面里能看到完整手掌 |
| 手势切换不灵敏 | 防抖帧数偏高 | `js/config.js` 里把 `stableFrames: 3` 改成 `2`（太快易误触） |
| 笔迹抖动明显 | 平滑系数偏低 | `smoothing: 0.55` 调大到 `0.7`（会更"黏手"） |
| 线条太细/太粗 | 手掌大小影响笔宽 | 手离镜头近一点=笔粗；或用剪刀手手势/工具按钮固定粗细 |
| 误触发换色/清空 | 手势在镜头里变形 | 手掌正对镜头、五指张开；提高 `gestureThreshold` 到 `0.7` |
| 捏合撤销总误触 | 捏合阈值太宽松 | 调小 `pinchRatio`（如 `0.035`） |
| 粒子效果变卡 | 同屏粒子太多 | `js/config.js` 里把 `particles.max` 调低（如 1200），或关闭其他占显卡的标签页；也可切到"笔迹模式"（更轻量） |
| 想要画笔而不是粒子 | 模式选择 | 点侧栏"笔迹模式"按钮，或地址加 `?mode=ink` |
| 3D 模式（银河/星环）黑屏/卡顿 | 需要 WebGL 与硬件加速 | 浏览器设置里开硬件加速；粒子太多则把 `js/config.js` 里 `space.count`/`galaxy.stars` 调低（如 6000/5000）；首次进入需联网加载 Three.js |

## 页面与网络问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 页面白屏 / 摄像头报错 | 直接双击打开了 index.html | 摄像头只能在 https 或 localhost 下用：`node scripts/serve.js` 后开 localhost:8000 |
| 状态灯一直"加载识别模型…" | 首次下载模型失败（约 8MB，走 Google CDN；仅在开摄像头时才需要） | 检查网络/代理；确认能访问 `storage.googleapis.com`；换网络后重试；演示模式不受影响 |
| `node` 不是内部或外部命令 | Node 没装好或没重启终端 | 重装 Node.js LTS；重开命令行窗口 |
| `Error: listen EADDRINUSE` 端口被占 | 8000 端口已有程序 | 换端口：`node scripts/serve.js 8080` → 开 localhost:8080 |
| F12 控制台一堆红色报错 | 各类原因 | 截图发给 AI 助手定位（模板见顶部） |

## GitHub 与部署问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `git push` 要求登录 | 凭据未配置 | 装 GitHub CLI 执行 `gh auth login`，或用 HTTPS + 浏览器弹窗登录 |
| push 被拒（non-fast-forward） | 远端有你本地没有的提交（如网页上改过 README） | 先 `git pull --rebase` 再 `git push` |
| Pages 打开 404 | 部署未完成/设置不对 | 仓库 Settings → Pages 确认 Source 为 `main` 分支根目录；等 1-2 分钟后强刷 |
| 改了代码线上没变化 | CDN/浏览器缓存 | `Ctrl+F5` 强制刷新；等 Actions/部署完成 |
| 在线版打不开摄像头 | 非安全上下文 | GitHub Pages 自带 https，正常可用；若用自定义域名需配置 https |

## 自检清单（出问题先过一遍）

- [ ] `node -v` 有版本号
- [ ] 用 localhost:8000 打开的（不是 file://）
- [ ] 摄像头权限 = 允许，且没被其他软件占用
- [ ] 光线充足、手掌完整入镜
- [ ] F12 控制台没有红色报错
- [ ] 改参数后刷新了页面（Ctrl+F5）
