心态与地图

vibecoding 的核心不是"背语法"，而是一个循环：描述 → 生成 → 验证 → 修改。你负责描述想要什么、判断结果对不对；AI 负责写代码。这门课的全部内容，就是带你把这个循环完整跑通一遍。

整个项目的数据流只有三段。记住这张图，后面所有代码都能对上号：

01

装工具

只需要 3 样东西，全部免费：

工具用途下载地址验证命令
Node.js跑本地服务器、跑测试nodejs.org（选 LTS）node -v
VS Code看代码、改代码code.visualstudio.com能打开就行
Git保存版本、上传 GitHubgit-scm.comgit --version

装完后打开命令行（Windows 按 Win+R 输入 cmd 回车），逐条输入验证命令，看到版本号（如 v22.22.0）就是成功。

再注册一个 GitHub 账号（github.com/signup）。想用命令行上传的话，装 GitHub CLI 后执行：

gh auth login
为什么需要 Node.js？ 摄像头权限只在 https 或 localhost 下可用，所以页面必须通过本地服务器打开，直接双击 index.html 是用不了摄像头的。Node 就是用来一键启动这个服务器的。
02

把项目跑起来

git clone https://github.com/mayuhan78855/gesture-sketchbook.git
cd gesture-sketchbook
node scripts/serve.js

浏览器打开 http://localhost:8000：

  1. 弹出摄像头授权 → 点"允许"。右上角状态灯变绿、显示"已就绪"。
  2. 手伸到镜头前 30–60cm，张开手掌——移动手，指尖拖出发光粒子流（默认粒子模式；点"笔迹模式"可切回画笔）。
  3. 试试其他手势：握拳换颜色、食指上指开构造线、剪刀手换笔刷、点赞清空。
  4. 没有摄像头？点右侧"演示模式"，一只虚拟手会自动表演全部交互。
03

读懂代码：看懂 5 个核心文件

每个文件只干一件事——这是好项目的通例，也是你能快速上手的理由：

文件你要理解的一件事
js/config.js所有"可调参数"集中在这：颜色、笔刷、平滑、阈值、粒子数量。改这里 = 改行为
js/effects.js手势→粒子效果注册表：一个条目 = 一种手势的效果，加新效果就加条目
js/particles.js粒子池、力场（引力/涡流/掌风）与辉光拖影渲染
js/app.js模式切换；笔迹模式动作在 onGesture()，粒子模式在 particleFrame() 走注册表
js/gestures.jsrecognizeForVideo() 每帧调一次，吐出 21 个关键点 + 手势名
js/sketch.js笔迹模式：begin() / addPoint() / end()——一笔的生命周期

推荐阅读顺序：config.js → effects.js（注册表）→ app.js 的 particleFrame → particles.js 的 update → gestures.js 的 _handle。

两个值得停下来想 1 分钟的细节：

防抖——stableFrames: 3 表示"连续 3 帧识别到同一手势才生效"。没有它，手势会在握拳/张开之间闪烁，颜色会连跳好几次。
平滑——smoothing: 0.55 是指数平滑，让笔迹跟手又不抖成筛糠。这两个参数就是手势交互"手感"的全部秘密。

04

vibecoding 工作法：怎么让 AI 帮你干活

以后做任何项目，都按这三步用 AI 助手（Claude / Cursor / Copilot 都行）：

  1. 描述目标，不说实现："我要一个网页，摄像头识别握拳后把画笔换成红色。"——先让它跑起来，再问细节。
  2. 指着代码问为什么："stableFrames 调成 1 会怎样？"——让 AI 解释任何你看不懂的行，问到懂为止。
  3. 小步改 + 立刻验证：每次只改一个参数 → 刷新页面 → 确认效果 → 满意就提交。永远别一次改十个地方。

万能提问模板：

我在做一个浏览器手势绘画项目（仓库：xxx）。
现在我想要【你想要的效果】。
请先解释需要改动哪个文件、为什么，再给出具体修改。
05

毕业任务：改一个参数，推上 GitHub

这是证明你"看懂了"的关键一步，也是作品集里最有说服力的提交记录：

  1. 用 VS Code 打开 js/config.js，把颜色数组改成你喜欢的： 
    colors: ["#e8f6ff", "#ff5d6c", "#7b6cff", "#35e08c"],
  2. 保存 → 刷新页面 → 按键盘 1-4 检查新颜色生效。
  3. 提交并推送： 
    git add js/config.js
git commit -m "feat: 换上我的画笔配色"
git push
  4. 一分钟后打开你的仓库页面，点最近一次提交，应能看到这行改动；GitHub Pages 上的在线版本也会自动同步。
完成标志：GitHub 仓库的 commit 列表里，出现一条你自己写的提交。这就是你在 vibecoding 世界里的第一个签名。进阶任务：打开 js/effects.js，仿照「能量爆发」改出一个你自己的粒子效果（文件头有三步指南），保存刷新立刻可见。
