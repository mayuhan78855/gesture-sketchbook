故障排查与常见问题

按"现象 → 原因 → 解决"组织。解决不了时：按 F12 打开浏览器控制台，把红色报错截图发给 AI 助手。

万能求助模板："我在跑 gesture-sketchbook 项目（本地 node scripts/serve.js 启动），报错如下：……请帮我定位。" 附上控制台截图。

● 摄像头问题

现象原因与解决
"摄像头权限被拒绝了"之前点过"拒绝"被浏览器记住。点地址栏左侧锁/摄像头图标 → 改为"允许" → 点页面"重试摄像头"；或打开 chrome://settings/content/camera 检查
"没有检测到摄像头"检查笔记本摄像头物理挡板/开关；外接摄像头换 USB 口重插
"摄像头被其他程序占用了"关闭 Zoom / OBS / 腾讯会议等占用摄像头的软件 → 点"重试摄像头"
卡在"正在打开摄像头…"驱动异常或被安全软件拦截：重启浏览器；设备管理器检查摄像头驱动
不想开摄像头点"演示模式"，虚拟手自动演示全部手势

● 识别与交互问题

现象原因与解决
手伸过去但不画光线太暗 / 背景太乱 / 手太远。开灯、面对纯色背景、手掌距镜头 30–60cm 且完整入镜
手势切换不灵敏js/config.js 里 stableFrames: 3 改成 2（再小容易误触）
笔迹抖动明显smoothing: 0.55 调大到 0.7（代价是更"黏手"）
线条太细/太粗手离镜头越近笔越粗；或用剪刀手手势固定粗细
误触发换色/清空手掌正对镜头五指张开；把 gestureThreshold 提到 0.7
捏合撤销总误触调小 pinchRatio（如 0.035）

● 页面与网络问题

现象原因与解决
页面白屏 / 摄像头不可用直接双击打开了 index.html。摄像头只能在 https 或 localhost 下用：node scripts/serve.js 后开 localhost:8000
一直"加载识别模型…"首次需联网下载约 8MB 模型（Google CDN）。检查网络/代理，确认能访问 storage.googleapis.com，换网重试
node 不是内部或外部命令Node 没装好或没重启终端：重装 LTS 版本，重开命令行
Error: listen EADDRINUSE8000 端口被占：node scripts/serve.js 8080 换端口

● GitHub 与部署问题

现象原因与解决
push 要求登录装 GitHub CLI 执行 gh auth login；或 HTTPS 方式用浏览器弹窗登录
push 被拒 non-fast-forward远端有你本地没有的提交（比如在网页上改过 README）：先 git pull --rebase 再 push
GitHub Pages 打开 404Settings → Pages 确认 Source 是 main 分支根目录；等 1–2 分钟后强刷
改了代码线上没变化Ctrl+F5 强刷；等部署完成（仓库 Actions 页可看进度）
在线版打不开摄像头GitHub Pages 自带 https，正常可用；自定义域名需配置 https

● 出问题先过一遍自检清单

  • node -v 有版本号
  • 页面是用 localhost:8000 打开的（不是 file://）
  • 摄像头权限 = 允许，且没被其他软件占用
  • 光线充足、手掌完整入镜
  • F12 控制台没有红色报错
  • 改参数后刷新了页面（Ctrl+F5）
