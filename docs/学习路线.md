# vibecoding 手势交互学习路线(零基础陪跑版)

> 这份教程假设你**完全没写过代码**。每一小步都附命令和"你应该看到什么"。
> 全程跟着做,你会在自己的 GitHub 上拥有一个能跑的手势交互作品。
> 项目成品在本仓库里,这份教程教的是"它是怎么来的、怎么改"。

![最终成品](../assets/demo.gif)

## 阶段 0 · 心态与地图(5 分钟)

vibecoding 的核心不是"背语法",而是**描述 → 生成 → 验证 → 修改**的循环。你负责描述想要什么、判断结果对不对;AI 负责写代码。这门课的全部内容就是带你把这个循环跑通一遍。

整个项目的数据流只有三段,记住这张图,后面所有代码都能对上号:

```
┌─────────────┐      ┌──────────────────┐      ┌─────────────────┐
│ 摄像头        │ ──▶ │ MediaPipe 手势识别  │ ──▶ │ 3D星环/粒子/笔迹    │
│ 视频帧(每秒60) │      │ 21个关键点 + 手势名  │      │ 星环 · 粒子 · 笔迹   │
└─────────────┘      └──────────────────┘      └─────────────────┘
     gestures.js              gestures.js    space3d.js · particles.js · effects.js
```

## 阶段 2 · 把项目跑起来(10 分钟)

```bash
git clone https://github.com/mayuhan78855/gesture-sketchbook.git
cd gesture-sketchbook
node scripts/serve.js
```

浏览器打开 <http://localhost:8000>:

1. 弹出摄像头授权 → 点"允许"。
2. 把手伸到镜头前 30-60cm，**张开手掌**——默认是 3D 星环模式：挥动手掌，星环随你旋转加速；握拳收缩、捏合聚合成星球；侧栏可切换粒子/笔迹模式。
3. 没有摄像头或不想开?点右侧"演示模式",看虚拟手自动表演全部手势。

**你应该看到什么**:右上角状态灯变绿"已就绪";你移动手掌,画布上跟着画出线条;握拳时弹出"颜色 → xxx"气泡。

## 阶段 3 · 读懂代码(30 分钟,看 5 个文件)

每个文件只干一件事,这是好项目的通例:

| 文件 | 行数级 | 你要理解的一件事 |
|------|--------|----------------|
| `js/config.js` | ~85 行 | 所有"可调参数"集中在这,改这里 = 改行为 |
| `js/space3d.js` | ~200 行 | 3D 星环:Three.js 粒子云、相机跟随、聚合/分裂/超新星 |
| `js/effects.js` | ~120 行 | **手势→粒子效果注册表**:一个条目 = 一种手势的效果,加新效果就加条目 |
| `js/particles.js` | ~180 行 | 粒子池、力场(引力/涡流/掌风)与辉光拖影渲染 |
| `js/app.js` | ~330 行 | 模式切换;笔迹模式动作在 `onGesture()`,粒子模式在 `particleFrame()` 走注册表 |
| `js/gestures.js` | ~200 行 | `recognizeForVideo()` 每帧调一次,吐出 21 个关键点 + 手势名 |
| `js/sketch.js` | ~250 行 | 笔迹模式:`begin()/addPoint()/end()` 一笔的生命周期 |

推荐阅读顺序:`config.js` → `effects.js`(注册表) → `app.js` 的 `particleFrame` → `particles.js` 的 `update` → `gestures.js` 的 `_handle`。

两个值得停下来想 1 分钟的细节:

- **防抖**：`stableFrames: 3` 表示“连续 3 帧识别到同一手势才生效”。没有它，手势会在握拳/张开之间闪，颜色会连跳。
- **平滑**：`smoothing: 0.55` 是指数平滑，让笔迹跟手又不会抖成筛糠。这两个参数就是手势交互手感的全部秘密。

## 阶段 4 · vibecoding 工作法(AI 怎么帮你)

以后你做任何项目,都可以按这三步用 AI 助手(Claude / Cursor / Copilot 都行):

1. **描述目标,不说实现**:"我要一个网页,摄像头识别握拳后把画笔换成红色" -- 先让它跑起来,再问细节。
2. **指着代码问为什么**:"`stableFrames` 调成 1 会怎样?" 让 AI 解释任何你看不懂的行。
3. **小步改 + 立刻验证**:每次只改一个参数 → 刷新页面 → 确认效果 → 满意就提交。

万能提问模板:

```
我在做一个浏览器手势绘画项目(仓库:xxx)。
现在我想要【你想要的效果】。
请先解释需要改动哪个文件、为什么,再给出具体修改。
```

## 阶段 5 · 毕业任务:改一个参数,推上 GitHub(20 分钟)

这是证明你"看懂了"的关键一步,也是面试/作品集里最有说服力的提交记录。

1. 用 VS Code 打开 `js/config.js`，把颜色数组改成你喜欢的：
   ```js
   colors: ["#e8f6ff", "#ff5d6c", "#7b6cff", "#35e08c"],
   ```
2. 保存 → 刷新页面 → 按键盘 `1-4` 检查新颜色生效。
3. 提交并推送:
   ```bash
   git add js/config.js
   git commit -m "feat: 换上我的画笔配色"
   git push
   ```
4. 一分钟后打开你的仓库页面,点最近一次提交,应能看到这行改动;GitHub Pages 版本也会自动同步。

**完成标志**:GitHub 仓库的 commit 列表里出现一条你自己写的提交。

进阶任务:打开 `js/effects.js`,仿照「能量爆发」改出一个你自己的粒子效果(文件头有三步指南),保存刷新立刻可见——这就是注册表的好处。
